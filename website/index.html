Azi

The browser extension that remembers so you don't have to.

A personal, cross-browser bookmark library. A lightweight extension forwards every new bookmark to a Cloudflare Worker, which scrapes the page, generates tags with AI, and indexes everything for search — all asynchronously, so your browser never waits on it.

Features

Cross-browser

One codebase, real MV3 extension on Chrome, Edge, and Firefox via webextension-polyfill.

AI tagging

Every new bookmark is scraped and tagged automatically by a Workers AI model — no manual filing.

AI category suggestions

Unfiled bookmarks get a suggested category, and a larger model can propose whole-category renames and merges.

Full-text search

BM25-ranked full-text search over titles, tags, and scraped page content, with AI query expansion when an exact search comes up empty.

Semantic (AI) search

Meaning-based search that finds a bookmark even when its title never mentions your search terms.

Bulk import

Import your entire existing bookmark tree in one go, with smart skip-unchanged logic on repeat runs.

Library view

A full browsable Library page — folder-tree category browsing, tag sidebar, and live search.

Per-account login

Real accounts with email-based access — your bookmarks are yours, isolated from every other account.

Getting it

Azi isn't listed on the Chrome or Firefox extension stores — it's a self-hosted, personal project you run yourself. Clone the repo, follow the setup steps in the README, and load it as an unpacked extension.
